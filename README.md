AI Jobs EDA Analysis
Overview

This project uses exploratory data analysis (EDA) with pandas to answer business-oriented questions about AI job postings and the skills associated with them.

What I Did
Explored the dataset structure and checked data quality
Investigated patterns in job titles, required skills, and skill groupings
Used pandas to filter, group, and summarize the data
Visualized key findings with charts
